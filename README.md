# 🚀 NexusAI - High-Conversion Tech Product Landing Page

[![Live Demo](https://img.shields.io/badge/Live_Demo-Interactive_Landing_Page-00F2FE?style=for-the-badge&logo=github)](https://af023.github.io/Tech-product-landing-page/)

## 📌 Overview
NexusAI is a modern, responsive **Tech Product Landing Page** built with clean HTML5, Tailwind CSS, and vanilla JavaScript. 

Designed for SaaS platforms and enterprise software launches, it demonstrates professional UI/UX standards, smooth mobile menu interactions, active contact form handling, and a dynamic bilingual (PT/EN) internationalization engine.

---

## ✨ Key Features
- **Responsive Navigation & Mobile Drawer:** Full layout responsiveness with mobile menu toggle.
- **Dynamic Bilingual Switch (i18n):** Real-time text and placeholder translation engine between English and Portuguese.
- **Glassmorphism Visual Style:** Frosted blur cards, glowing neon borders, and clean typography.
- **Interactive Pricing Matrix:** Clear plan tiers (Starter, Pro, Enterprise) with visual highlights.
- **Lead Capture Form:** Interactive form submission logic with instant user feedback.

---

## 🛠️ Tech Stack
- **Markup:** HTML5 (Semantic).
- **Styling:** Tailwind CSS (Utility-first framework with custom glassmorphic panels).
- **Interactivity:** Vanilla JavaScript (ES6+).
- **Vector Icons:** Lucide Icons.
